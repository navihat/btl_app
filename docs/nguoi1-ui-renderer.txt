--------------------------------------------------------------
1. Ý TƯỞNG VÀ LÝ DO LỰA CHỌN
--------------------------------------------------------------

Nhiệm vụ của Người 1 là xây dựng toàn bộ giao diện người dùng
(Renderer Process) cho ứng dụng Electron. Đây là lớp mà giảng
viên trực tiếp tương tác, gồm 4 màn hình chính.

Tại sao dùng React?
  - React cho phép chia UI thành các component độc lập, tái sử dụng.
  - State management đơn giản bằng useState/useEffect, phù hợp
    với quy mô MVP của dự án.
  - electron-vite tích hợp sẵn Vite + React, HMR (Hot Module
    Replacement) giúp phát triển nhanh mà không cần reload cả app.

Tại sao không dùng Redux hay Zustand?
  - Ứng dụng chỉ có 4 màn hình, không có shared state phức tạp.
  - Mỗi page tự fetch data từ IPC khi mount → đủ dùng cho MVP.

Tại sao dùng window.api thay vì import trực tiếp service?
  - Electron chia 2 process: Main (Node.js) và Renderer (Browser).
  - Renderer không được phép import module Node.js (fs, path...) trực tiếp.
  - Preload script (contextBridge) tạo ra window.api như một "cầu nối"
    an toàn giữa 2 process.

Cấu trúc điều hướng:
  - Không dùng React Router để tránh phụ thuộc thêm.
  - App.tsx quản lý một state kiểu Page (union type), render page
    tương ứng — đơn giản và đủ dùng cho 4 màn hình.

2. CẤU TRÚC FILE NGƯỜI 1 PHỤ TRÁCH

--------------------------------------------------------------
3. SETUP VÀ CẤU HÌNH
--------------------------------------------------------------

Bước 1: Cài đặt (Person 3 đã scaffold, Person 1 chỉ cần chạy)
  npm install

Bước 2: Khởi động dev
  npm run dev
  → electron-vite sẽ:
    - Build main process ra out/main/index.js
    - Build preload ra out/preload/index.js
    - Khởi Vite dev server tại http://localhost:5173
    - Tự động mở cửa sổ Electron

Bước 3: Xem thay đổi giao diện ngay lập tức
  → Chỉnh sửa bất kỳ file .tsx / .css nào trong src/renderer/
  → Electron window tự reload nhờ HMR (Hot Module Replacement)


--------------------------------------------------------------
4. CHI TIẾT TỪNG FILE
--------------------------------------------------------------

---- src/preload/index.ts ----

Dùng contextBridge.exposeInMainWorld để tạo window.api.
Đây là bức tường cách ly: Renderer chỉ gọi qua API này,
không thể trực tiếp dùng ipcRenderer.

  window.api = {
    questionCreate(data)         → gửi IPC 'question:create'
    questionUpdate(id, data)     → gửi IPC 'question:update'
    questionDelete(id)           → gửi IPC 'question:delete'
    questionList(filters?)       → gửi IPC 'question:list'
    examCreate(data)             → gửi IPC 'exam:create'
    examAddQuestions(id, ids[])  → gửi IPC 'exam:addQuestions'
    examDelete(id)               → gửi IPC 'exam:delete'
    examList()                   → gửi IPC 'exam:list'
    examGet(id)                  → gửi IPC 'exam:get'
  }

Tất cả đều dùng ipcRenderer.invoke() → trả về Promise.


---- src/renderer/env.d.ts ----

Khai báo global interface Window để TypeScript hiểu window.api.
Nếu thiếu file này, tất cả lời gọi window.api.xxx đều bị lỗi
kiểu "Property 'api' does not exist on type 'Window'".

  declare global {
    interface Window {
      api: { ... }
    }
  }


---- src/renderer/App.tsx ----

Trạng thái điều hướng dùng kiểu union:

  type Page =
    | { name: 'questions' }
    | { name: 'exams' }
    | { name: 'create-exam' }
    | { name: 'exam-detail'; examId: string }

Sidebar chứa 2 nav item: "Ngân hàng câu hỏi" và "Quản lý đề thi".
Khi chuyển trang (ví dụ nhấn "Chi tiết" một đề), setPage được
gọi với { name: 'exam-detail', examId: id }.


---- src/renderer/pages/QuestionBankPage.tsx ----

Màn hình chính cho CRUD câu hỏi.

State:
  questions[]         ← danh sách hiện tại
  filterDifficulty    ← filter độ khó
  filterTopic         ← filter chủ đề (tìm kiếm text)
  showModal           ← modal thêm/sửa
  editId              ← null = thêm mới, string = sửa
  form                ← dữ liệu form đang nhập

Logic:
  loadQuestions()  → window.api.questionList(filters)
  openCreate()     → reset form, mở modal
  openEdit(q)      → điền form với dữ liệu câu hỏi, mở modal
  handleSubmit()   → gọi questionCreate hoặc questionUpdate
  handleDelete(id) → confirm → questionDelete → reload

Form câu hỏi:
  - TextArea cho nội dung
  - 4 input cho đáp án A/B/C/D
  - Radio button để chọn đáp án đúng (correctOptionIndex)
  - Select cho độ khó, Input cho chủ đề

Hiển thị bảng:
  - Mỗi hàng hiển thị nội dung câu hỏi, 4 đáp án (đáp án đúng
    có màu xanh lá), chủ đề, badge độ khó, nút Sửa/Xóa.


---- src/renderer/pages/CreateExamPage.tsx ----

Form đơn giản để tạo đề thi mới.

Fields:
  title       (bắt buộc)
  description (tùy chọn)
  duration    (phút, bắt buộc > 0)
  difficulty  (easy/medium/hard/mixed)

Khi submit:
  → Validate client-side trước
  → Gọi window.api.examCreate(dto)
  → Sau khi tạo thành công, chuyển ngay sang ExamDetailPage
    để giảng viên có thể thêm câu hỏi vào đề mới tạo.


---- src/renderer/pages/ExamListPage.tsx ----

Danh sách tất cả đề thi đã tạo.

  Cột: Tên đề, Mô tả, Thời gian, Mức độ, Số câu, Ngày tạo
  Hành động: "Chi tiết" (chuyển sang ExamDetailPage), "Xóa"

Xóa có confirm dialog để tránh xóa nhầm.
Tên đề thi là link bấm được → chuyển sang chi tiết.


---- src/renderer/pages/ExamDetailPage.tsx ----

Màn hình phức tạp nhất, gồm 2 phần:

  Phần 1: Header thông tin đề (tên, thời gian, mức độ, mô tả)
  Phần 2: Danh sách câu hỏi đã có trong đề

  Nút "+ Thêm câu hỏi" → mở modal ngân hàng câu hỏi

  Modal ngân hàng:
    - Hiển thị TẤT CẢ câu hỏi CHƯA có trong đề này
    - Có filter độ khó + tìm kiếm theo chủ đề (client-side)
    - Checkbox để tick nhiều câu cùng lúc
    - Nút "Thêm N câu" gọi window.api.examAddQuestions()

  Cách lọc câu hỏi chưa có trong đề:
    const existingIds = new Set(exam.questionIds)
    setBank(all.filter(q => !existingIds.has(q.id)))


--------------------------------------------------------------
5. LUỒNG DỮ LIỆU (DATA FLOW)
--------------------------------------------------------------

  [Giảng viên bấm "Thêm câu hỏi"]
       ↓
  React setState(showBankModal = true)
       ↓
  window.api.questionList()    ← ipcRenderer.invoke('question:list')
       ↓                               ↓
  [Renderer nhận Promise]        [Main process: questionHandlers.ts]
       ↓                               → QuestionService.listQuestions()
  setBank(filtered)                    → JsonQuestionRepository.findAll()
       ↓                               → đọc data/questions.json
  Render danh sách checkbox            → trả về Question[]
       ↓
  [Giảng viên tick + bấm "Thêm"]
       ↓
  window.api.examAddQuestions(examId, selectedIds[])
       ↓
  [Main: ExamService.addQuestions()]
    → ManualSelectionStrategy.select()
    → JsonExamRepository.update()
    → ExamSubject.notify('created/updated')
       ↓
  setShowBankModal(false)
  loadExam()   ← tải lại exam để cập nhật số câu


--------------------------------------------------------------
6. LƯU Ý KHI PHÁT TRIỂN
--------------------------------------------------------------

  - Luôn dùng window.api.xxx, KHÔNG import trực tiếp service/repo.
  - Mọi lỗi từ IPC đều được catch trong try/catch → setError(msg).
  - Sau khi tạo/sửa/xóa phải gọi lại hàm load để đồng bộ UI.
  - filterTopic dùng useState + useCallback để tránh re-render thừa.
  - Styles không dùng CSS Modules hay Tailwind mà dùng global CSS
    với CSS variables (--primary, --danger...) để dễ chỉnh màu.
